NovaMart Premium Black & Gold Store
====================================
Open index.html with VS Code Live Server.

Pages:
index.html (Home)
mens.html
womens.html
new-arrivals.html
product.html?id=4
cart.html
checkout.html
login.html
account.html
track.html
admin.html

Design:
Deep black #050505 / #090909, gold #D4AF37, white.
Each page is a separate HTML document. The Home page does not contain the other page sections.

Demo functionality:
- Add to cart and quantity controls use browser localStorage.
- Checkout creates a local demo order.
- Track Order finds orders created in this browser using the generated Order ID.
- Login and Admin dashboard are UI demos only.

Production note:
Real payments, secure authentication, cross-device order tracking, inventory and admin access require a backend/database and payment gateway. Product photos load from Unsplash URLs, so internet is required for those images.
